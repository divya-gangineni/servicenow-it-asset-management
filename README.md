# IT Asset Management System | ServiceNow Zurich

## Overview

This project is a custom IT Asset Management application developed using ServiceNow Zurich.

The application helps organizations manage IT assets, allocate assets to employees, monitor asset status, generate reports, and visualize data using dashboards.

---

## Features

- Asset Management
- Asset Allocation
- Asset Return
- Asset Status Tracking
- Reports
- Dashboard
- Pie Chart Analytics
- Update Sets
- Role-based Access
- Custom Tables
- Custom Forms
- Custom Lists

---

## Technologies Used

- ServiceNow Zurich
- App Engine Studio
- Platform Analytics
- Reports
- Dashboards
- Update Sets

---

## Modules

### Asset Management

Manage all IT assets.

### Asset Allocation

Allocate assets to employees.

### Asset Return

Track returned assets.

### Reports

Generate Asset Allocation reports.

### Dashboard

Visualize asset allocation using Pie Charts.
